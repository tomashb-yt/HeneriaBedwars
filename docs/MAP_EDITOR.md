# Configurateur de maps

**Statut :** vision définie, aucune fonction implémentée.

## Objectif et périmètre

Permettre à un administrateur de rendre configurable en jeu n'importe quelle map Zombies.

## Informations connues

Le parcours principal sera une GUI associée à une session d'édition explicite. Une définition
utilisera un identifiant stable, une version et des collections extensibles pour zones, portes,
spawns, achats, machines, objectifs et chemins. Le nombre de spawns ne sera pas plafonné dans le
modèle. La validation affichera les éléments complets, manquants ou incohérents avant activation.
Une map modèle ne sera jamais modifiée par une partie runtime.

## À compléter

Schéma de données, outil d'administration, historique/annulation, sélection de positions,
prévisualisation, validation géométrique, import/export et permissions fines.
